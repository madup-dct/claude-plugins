# copy-tone-gate — 카피 말투 게이트

문학적으로 멋 부린 AI 헤드라인은 발표장에서 아무도 입에 담지 않는다. 이 게이트는 그걸 쓰는 순간 잡는다.
(기원: "'낯선 말 여덟 개' 이런 거 누가 쓰냐, 구어체로 해라"라는 실제 피드백)

## 판정 기준 — 소리 테스트 (단 하나의 원칙)

**발표자가 청중 앞에서 그 문장을 그대로 입으로 말할 수 있으면 통과. 어색하면 탈락.**
모든 헤드라인·리드를 소리 내어 읽어본다(상상으로라도). "다음 장입니다, ___" 뒤에 자연스럽게 붙는지 본다.

## 금지 패턴 (탈락 즉시 재작성)

1. **문학적 수식 명사구 제목** — "낯선 말 여덟 개", "~의 재구성", "~라는 질문", "N개의 시선"
2. **"A — 전부 B의 C 버전"식 em-dash 병렬 선언** — 대시로 멋 부린 요약 구조
3. **"~라면, ~입니다" 대칭 대구** — 사람은 즉석에서 앞뒤를 저울처럼 맞춰 말하지 않는다
4. **헤드라인의 문어 종결** — "~이다", "~한다", "~못했다" (표·카드 안 본문의 ~다체는 허용)
5. **선언·과장조** — "증명합니다", "시작됩니다", "~이 되다", "여정"류 브로셔 명사
6. **3연속 같은 리듬의 병렬 제목** — 기계적 대구
7. **관념 명사 헤드라인** — "관념 설계가 아니다" 같은, 말로 하면 아무도 안 쓰는 표현

## 처방

- 헤드라인 = 발표체 구어: "~습니다 / ~하죠 / ~가시죠 / ~보겠습니다" 또는 짧은 자연 구어("이미 돌고 있습니다")
- 리드 문장도 ~습니다체 — 발표자가 이어서 말할 두 번째 문장
- 청중이 물을 법한 질문을 제목으로 써도 좋다 ("또 새 시스템이에요?")
- 슬로건(제품 태그라인)은 예외 — 단 덱당 최대 2회(커버·클로징)만
- 본문 표·카드 셀은 개조식·~다체 허용 (한국 실무 문서 관행)

## 적용 시점

1. **쓰는 순간** — 초안 헤드라인을 쓰자마자 소리 테스트
2. **출고 직전** — 전 슬라이드 제목만 모아 위에서 아래로 소리 내어 1패스 (덱 기준 2분)

## 전체 스윕 절차 (기존 덱 교정 요청 시)

1. 덱에서 헤드라인·리드·디바이더 문구를 전부 추출한다 (본문 표·카드 셀은 제외).
2. 각 문장에 소리 테스트 + 금지 패턴 7종을 대조해 탈락 문장을 목록화한다.
3. "원문 → 수정안" 표로 제시하고, 적용 후 렌더를 다시 확인한다.
4. 수정안이 새 금지 패턴(특히 "~다면" 대구 재도입)을 만들지 않았는지 역검사한다.

## 비포/애프터 (실제 교정 사례)

| 탈락 (AI 말투) | 통과 (사람 말투) |
|---|---|
| 낯선 말 여덟 개 — 전부 사람 조직의 디지털 버전 | 용어 여덟 개만 정리하고 가시죠 |
| 여기까지가 설명이라면, 지금부터는 실물입니다 | 이제 실제로 돌아가는 걸 보여드리겠습니다 |
| 문서가 일이고, 기록은 부산물이다 | 일은 열심히 하는데, 남는 기록이 없습니다 |
| 검색에서 쌓아온 걸 옮기는 여정입니다 | 검색에서 쌓아온 걸 옮겨 갑니다 |
| 세 그룹 모두 우리 자리에 도달하지 못했다 | 아직 아무도 이 자리엔 오지 못했습니다 |
